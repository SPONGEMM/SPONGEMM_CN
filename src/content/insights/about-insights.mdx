## 这个栏目是干什么的

观点洞见用来记录与分子模拟、分子建模、计算化学方法相关的**观点、观察与经验**。文章源文件存在 `src/content/insights/`，欢迎通过 GitHub Pull Request 投稿。

每篇文章是一个 `.mdx` 文件，顶部 YAML frontmatter 写元信息（标题、作者、日期、头像），正文用 Markdown 即可，需要的时候可以嵌入 Astro 组件。

## 公式

行内公式：势能由键合项 $U_{\text{bond}}$ 与非键合项 $U_{\text{nb}}$ 组成，即 $U = U_{\text{bond}} + U_{\text{nb}}$。

块级公式：

$$
U_{\text{LJ}}(r) = 4\varepsilon\left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^{6}\right]
$$

$$
F_i = -\nabla_i U(\mathbf{r}_1, \dots, \mathbf{r}_N)
$$

## 投稿方式

1. Fork [`spongemm/spongemm_cn`](https://github.com/spongemm/spongemm_cn)
2. 在 `src/content/insights/` 下新建一个 `.mdx` 文件
3. 写好 frontmatter 与正文，本地 `npm run dev` 预览效果
4. 提交 Pull Request，合并后下次部署即上线
