# 示例

### `命令名`：类型-><kbd>默认值</kbd>
※※※※※

类型项目：
英文名 | 中文名 | 备注
---|---|---
float | 浮点数 | 基本类型 
int | 整数 | 基本类型
string | 字符串 | 基本类型
enum | 选项 | 可选值详见具体命令
bool | 布尔值 | 0 或1
file | 文件名 | 文件路径中不要存在空格
CV | CV | 由`cv_in_file`定义的CV

# MD核心

## 系统信息

### `mdin`：file-><kbd>mdin.txt</kbd>
※※※※※
命令控制输入文件

### `cv_in_file`：file
※※※
CV控制输入文件

### `pbc`: bool-><kbd>1</kbd>
※※※
是否启用周期性边界条件

### `mode`: enum
※※※※※
使用模式

可选值  |  含义
--- | ---
NVE | NVE系综模拟
NVT | NVT系综模拟
NPT | NPT系综模拟
minimization | 能量最小化
rerun | 重跑轨迹

### `dt`: float-><kbd>1e-3</kbd>(非最小化); <kbd>1e-8</kbd>(最小化)
※※※※※
步长[ps]，仅在非重跑模式下可用

### `step_limit`: int-><kbd>1000</kbd>
※※※※※
模拟的总步数，仅在非重跑模式下可用

### `thermostat`: enum
※※※※※
使用的控温方式，仅在NVT模式和NPT模式下可用
可选值见[模块功能](/文档/CudaSPONGE文档/模块功能)

### `target_temperature`: float-><kbd>300.0</kbd>
※※※※
模拟的系综温度[K]，仅在NVT模式和NPT模式下可用

### `barostat`: enum
※※※※※
使用的控压方式，仅在NPT模式下可用
可选值见[模块功能](/文档/CudaSPONGE文档/模块功能)

### `target_pressure`: float-><kbd>1.0</kbd>
※※※※
模拟的系综压强[bar]，仅在NPT模式下可用

### `velocity_max`: float-><kbd>-1</kbd>
※※※
粒子速度的最大值[22.45 埃/皮秒]，防止某个粒子因为偶然速度过大造成系统崩溃。负数不作检查。
> 如需设置，300 K下的参考值为20
{.is-info}

### `default_in_file_prefix`: string
※※※※※
定义后，`xxx_in_file` 会自动寻找对应的的文件
如`coordinate_in_file` 会自动寻找`default_in_file_prefix`_coordinate.txt

### `coordinate_in_file`: file
※※※※※
坐标输入文件

### `velocity_in_file`: file
※※※※
速度输入文件

### `mass_in_file`: file
※※
质量输入文件

### `charge_in_file`: file
※※
电荷输入文件

### `residue_in_file`: file
※※
残基输入文件

### `end_pause`: bool-><kbd>0</kbd>
※※
结束程序时是否需要额外输入一个回车

### `device`: int-><kbd>0</kbd>
※※※
使用的GPU设备编号

### `dont_check_input`: bool-><kbd>0</kbd>
※※
不输出输入产生的警告
> 不输出警告很危险，请确保你明白这些警告的意义
{.is-warning}

## AMBER兼容

> AMBER的文件只在早期测试中使用，并保存了下来，但在后期的功能实现中，很多功能已不支持对AMBER格式文件的读取
{.is-warning}

### `amber_parm7`: file
※※
AMBER格式的拓扑输入文件

### `amber_rst7`: file
※※
AMBER格式的坐标输入文件

### `amber_irest`: bool-><kbd>1</kbd>
※
AMBER格式的坐标输入文件的参数，用以下逻辑判断该文件中是否包含速度信息
- 若设为0，则
  * 无速度信息
- 若设为1，则
  * amber_rst7中不包含时间信息，则无速度信息
  * amber_rst7中包含时间信息，则有速度信息

## 轨迹重跑

### `frame_limit`: int
※※※
重跑的总步数

### `rerun_start`: int-><kbd>0</kbd>
※※※

## 非键信息

### `skin`: float-><kbd>2.0</kbd>
※※
非键"皮肤"厚度[埃]
当某个原子移动超过 `skin` * `skin_permit` 以后，将会更新近邻表。近邻表将包含每个原子周围 `skin` + `cutoff` 内的粒子

### `cutoff`: float-><kbd>10.0</kbd>
※※※※※
非键截断距离[埃]
> 默认参数10.0埃对于非周期性边界条件下的模拟太小
{.is-info}

### `exclude_in_file`: file
※※
非键排除表输入文件

## 近邻表

### `neighbor_list_refresh_interval`: int-><kbd>0</kbd>
※※※
近邻表更新的间隔步数，若不为正，则任一原子移动超过 `skin` * `neighbor_list_skin_permit` 后自动更新

### `neighbor_list_max_atom_in_grid_numbers`: int-><kbd>80</kbd>
※※
近邻表中每个格子里最多的原子数量，用于分配内存

### `neighbor_list_max_neighbor_numbers`: int-><kbd>1200</kbd>
※※
每个原子最多近邻数量，用于分配内存

### `neighbor_list_skin_permit`: float-><kbd>0.5</kbd>
※※※
自动更新近邻表的逻辑里，允许原子移动的skin的比例。当`neighbor_list_skin_permit` = 0.5时是准确的，更大的值计算会更快但精度会有所下降

可选值 | 可选值
--- | ---

Y | XZ
Z | YZ

## 限制与约束

### `restrain_atom_id`: file
※※※
位置限制的原子序号

> 可以使用Xponge中的maskgen功能调用MDAnalysis生成该文件，详见`Xponge maskgen -h`
{.is-info}



### `restrain_coordinate_in_file`: file
※※※
位置限制的参考坐标

### `restrain_amber_rst7`: file
※※
位置限制的参考坐标(amber格式)

### `restrain_weight`: float-><kbd>20.0</kbd>
※※※
位置限制的力常数[$\rm kcal/mol/A^2$]

### `constrain_mode`: enum
※※※※
约束模式
可选值 | 含义
--- | ---
shake | SHAKE算法
simple_constrain | 简单约束算法

### `constrain_mass`: float-><kbd>3.3</kbd>(未给constrain_in_file);<kbd>0</kbd>(给了constrain_in_file)
※※

### `constrain_in_file`: file
※※
明确需要约束的键长的文件

> 在大多数时候这个文件是不需要提供的，因为程序会根据 `constrain_mass` 自动生成。
{.is-info}

### `constrain_angle`: bool-><kbd>0</kbd>
※
是否对质量小于 `constrain_mass` 的原子的键角进行约束

> 启用后，对复杂体系可能会造成约束很难收敛，并且对键角的约束是不物理的，不推荐开启。
{.is-warning}

> 以下命令仅在 `SITS_mode` 为非 ``observation`` 时启用
{.is-info}
---

### `SITS_k_numbers`: int-><kbd>40</kbd>
※※※
温度的份数

### `SITS_T_high`: float
※※※
温度积分的上区间，自动使用 `SITS_k_numbers`、`SITS_T_high` 和 `SITS_T_low` 线性插值获得温度格点

### `SITS_T_low`: float
※※※
温度积分的下区间，自动使用 `SITS_k_numbers`、`SITS_T_high` 和 `SITS_T_low` 线性插值获得温度格点

### `SITS_T`: float/../float
※※
温度的格点。该命令会被 `SITS_T_high` 和 `SITS_T_low` 无效

### `SITS_record_interval`: int-><kbd>1</kbd>
※
每隔`SITS_record_interval` 步记录一次能量

### `SITS_update_interval`: int-><kbd>100</kbd>
※
每隔`SITS_update_interval` 次记录更新一次偏置能的参数

### `SITS_pe_a`: float-><kbd>1</kbd>
※※※
记录能量时的乘数因子

### `SITS_pe_b`: float-><kbd>0</kbd>
※※※
记录能量时的平移参数[kcal/mol]

### `SITS_fb_bias`: float-><kbd>0</kbd>
※※
最终fb的平移因子

### `SITS_nk_rest`: bool-><kbd>0</kbd>(迭代模式);<kbd>1</kbd>(生产模式)
※
nk参数是否重新读入

### `SITS_nk_in_file`: file
※※※
nk参数重新读入文件

### `SITS_nk_fix`: bool-><kbd>0</kbd>(迭代模式);<kbd>1</kbd>(生产模式)
※
nk参数是否不变

---
> 以下命令仅在 `SITS_nk_fix` 为 ``0`` 时启用
{.is-info}
---
### `SITS_nk_rest_file`: file-><kbd>SITS_nk_rest_file</kbd>
※※※
nk重启文件

### `SITS_nk_traj_file`: file-><kbd>SITS_nk_traj.dat</kbd>

nk轨迹文件
